# 🔹 Text to Binary Converter

A simple and practical tool for converting **text to binary** and viewing the conversion details of each character. This program is written in **Python** and runs in the terminal.

---

## 🎯 Features

- 📝 **Text to Binary Conversion**: Each character is converted to 8-bit binary code
- 📊 **Display Details**: Shows character count and binary string length
- 📋 **Conversion Table**: Shows each character with its binary code
- 🔄 **Convert Again**: Convert new texts without exiting the program
- 🚪 **Easy Exit**: By typing `exit` or `no`

---

## 🚀 Installation & Run

### Prerequisites

- Python 3.6 or higher

### Commands

| Command | Description |
|---------|-------------|
| **Any text** | Convert text to binary |
| **exit** | Exit the program |
| **yes/y** | Continue converting |
| **no/n** | Exit the program |
